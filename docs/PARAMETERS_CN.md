# 命令行参数完整参考

本文一滴不差列出 `ea-FRDT` 的全部命令行参数、默认值与取值范围。

## 位置参数

| 参数 | 默认值 | 描述 |
|---|---|---|
| `delay_ms` | 无（必须给，否则显示帮助） | 每步之间的延迟毫秒数，支持小数（如 `0.5`、`0.01`）。`0` = 不限速，全速跑。`-m all` 未指定时默认 `10`。负数自动钳为 `0`。 |

## 帮助

| 参数 | 短写 | 描述 |
|---|---|---|
| `--help` | `-h` | 显示双语帮助并退出。 |

## 起点与步进

| 参数 | 短写 | 默认值 | 取值范围 | 描述 |
|---|---|---|---|---|
| `--start <x>` | `-a` | `1.0` | 有限数值，支持负数、科学计数法（`1e-3`）、工程计数法、十六进制 Raw（`0x3F800000`）、关键字 `min-normal`/`max-finite` | 行走起点。不能为 NaN/Inf。与 `-s` 互斥。 |
| `--subnormal` | `-s` | 关 | 无值 | 从该格式的最小非规格化数（min subnormal）开始向上走。与 `-a` 数值起点互斥。 |
| `--factor <r>` | `-k` | `1.02` | 正数，不能为 0、负数、NaN、Inf。支持科学计数法（`1.05e0`）。`<1e-10` 触发警告。 | 每步倍率。`>1` 递增到 +inf，`0<r<1` 递减到 0。 |
| `--step <s>` | `-g` | `x1.02` | `x1.02`（或 `x102`）/ `mululp` / `addulp` / `subulp` / `mululp-down` | 步进模式。`x1.02` = 乘倍率；`mululp` = 乘 `(1+1ULP)`；`addulp` = 加 `1ULP`；`subulp` = 减 `1ULP`；`mululp-down` = 乘 `(1-1ULP)`。 |

## 浮点格式

| 参数 | 短写 | 默认值 | 描述 |
|---|---|---|---|
| `--mode <m>` | `-m` | `f32` | 选择浮点格式。见下方完整列表。`all` = 并发跑全部格式（默认排除 DPD32/DPD64/DPD128/Dec128[BID]，需手动 `--only` 指定）。 |

### 17 种格式完整列表

| 模式值 | 显示名 | 类别 | 位宽 | 说明 |
|---|---|---|---|---|
| `f16` / `fp16` | FP16 | 原生 | 16 | IEEE 754 half precision |
| `f32` / `fp32` | FP32 | 原生 | 32 | IEEE 754 single（默认） |
| `f64` / `fp64` | FP64 | 原生 | 64 | IEEE 754 double |
| `fp4` | FP4(E2M1) | 自写位级 | 4 | 2 指数位 + 1 尾数位 |
| `fp6` | FP6(E3M2) | 自写位级 | 6 | 3 指数位 + 2 尾数位 |
| `fp8` / `fp8-e4m3` | FP8(E4M3) | 自写位级 | 8 | 4 指数位 + 3 尾数位 |
| `fp8-e5m2` | FP8(E5M2) | 自写位级 | 8 | 5 指数位 + 2 尾数位 |
| `bf16` | BF16(E8M7) | 自写位级 | 16 | Brain Float，8 指数位 + 7 尾数位 |
| `tf32` | TF32(E8M10) | 自写位级 | 19 | TensorFloat-32，8 指数位 + 10 尾数位 |
| `x87` | x87 | 纯软件 | 80 | x87 扩展精度 80 位仿真（无 `long double` 依赖） |
| `fp128` | FP128 | 纯软件 | 128 | 完整 112 位尾数仿真（无 libquadmath） |
| `dec32` / `decimal32` | Decimal32[BID] | 十进制 BID | 32 | 7 位有效数字 |
| `dec64` / `decimal64` | Decimal64[BID] | 十进制 BID | 64 | 16 位有效数字 |
| `dec128` / `decimal128` | Decimal128[BID] | 十进制 BID | 128 | 34 位有效数字，自研 UInt256 大整数 |
| `dpd32` / `dpd-dec32` | DPD32[DPD] | 十进制 DPD | 32 | 7 位有效数字，密封装十进制 |
| `dpd64` / `dpd-dec64` | DPD64[DPD] | 十进制 DPD | 64 | 16 位有效数字 |
| `dpd128` / `dpd-dec128` | DPD128[DPD] | 十进制 DPD | 128 | 34 位有效数字 |

## 显示与输出

| 参数 | 短写 | 默认值 | 取值 | 描述 |
|---|---|---|---|---|
| `--fmt <f>` | `-f` | `eng` | `eng` / `sci` / `full` | 数值显示格式。`eng` = 工程计数法；`sci` = 科学计数法；`full` = 完整小数展开。 |
| `--digits <n>` | `-d` | `6` | `-1` 或 `0~100` | sci/eng 尾数小数位。`-1` = 完整精度。 |
| `--bits <m>` | `--showbits` | `off` | `hex` / `bin` / `off`（或 `none`） | 值后面括号里附原始位型。`hex` = 十六进制；`bin` = 二进制按段分组。 |
| `--quiet` | `-q` | 关 | 无值 | 静默模式：不打每步输出，最后只出汇总表。 |
| `--json` | 无 | 关 | 无值 | 机器可读 JSON 输出。自动强制静默。每次运行输出一行 JSON（含 format/steps/elapsed_ms/steps_per_sec/reason/final_value/params/system/timestamp）。`-m all` 时输出 workers 数组。 |
| `--dump <file>` | 无 | 关 | 文件路径 | 把每步的原始字节二进制序列化到指定文件。自动强制静默。 |
| `--dump-packed` | 无 | 关 | 无值 | 紧凑记录宽度（tf32=3B 而非 4B）。 |
| `--dump-endian <e>` | 无 | `little` | `little`（别名 `le`/`cpu`）/ `big`（别名 `be`） | `--dump` 字节序。默认跟随 x86 CPU 原生小端；`big` 写入前翻转字节序。 |
| `--lang <zh|en>` | `-lang` / `--language` | `zh` | `zh` / `en` | 界面语言。错误消息、警告、汇总表都跟随。 |

## 并发（-m all）

| 参数 | 短写 | 默认值 | 描述 |
|---|---|---|---|
| `--jobs <spec>` | `-j` | `all`（全部逻辑核心） | worker/核心编号。支持单值（`-j 4`）、逗号列表（`-j 1,3,5`）、范围（`-j 1-4`）、混合（`-j 1,3-5`）。硬上限 = `std::thread::hardware_concurrency()`。 |
| `--only <list>` | `--modes` | 全部 17 种（实际排除 DPD/Dec128 默认组） | 逗号分隔的格式子集，例如 `--only fp32,fp64,dec64`。 |
| `--refresh <ms>` | `-r` | 单模式 `0`（每步刷新）；`-m all` 未指定时 `1000` | 监视器刷新间隔毫秒。`0` = 每步刷新。负数钳为 `0`。 |

## 控制

| 参数 | 短写 | 默认值 | 取值 | 描述 |
|---|---|---|---|---|
| `--timeout <s>` | `-t` | `0` | 非负整数秒 | 超时停止。`0` = 一直跑到溢出/下溢。负数钳为 `0`。 |
| `--loop <n>` | `-l` | `1` | `-1` = 无限；`1` = 单遍（默认）；`>1` = 重复 N 次；上限 `1000000`；`0` 自动当作 `1` | 循环次数。`-l -1` 且 `-t 0` 时触发 DoS 警告。 |

## 退出码

| 退出码 | 含义 |
|---|---|
| `0` | 正常结束（溢出/下溢/超时/循环完成） |
| `2` | 参数错误（解析失败、互斥冲突、越界值、未知格式） |

## 安全守卫

- `-l -1` 且 `-t 0`：黄色警告，提示可能 100% CPU。
- `-k < 1e-10`：黄色警告，提示步数可能爆炸。
- DPD32/DPD64/DPD128 在 `-m all` 并发模式下：黄色警告，需按 `y` 确认，10 秒未操作自动取消。
- Dec128[BID] 在并发模式下：黄色警告，需按 `y` 确认。
- 用户输入错误消息经过 `sanitize()` 过滤，去除 ANSI 转义和 C0 控制字符，防终端注入。
- hex 输入最多 32 字符（兼容 128 位浮点）。
- 起点不能为 NaN/Inf，倍率不能为 0/负数/NaN/Inf。

## 示例速查

```
ea-FRDT.exe 0                                # f32 从 1.0 ×1.02
ea-FRDT.exe 0 -a 100 -k 1.1                  # 从 100 起步 ×1.1
ea-FRDT.exe 0 -a 0x3F800000 -m f32          # Raw 位串起点
ea-FRDT.exe 0 -a max-finite -k 0.5           # 最大值递减到 0
ea-FRDT.exe 0 -m fp4 -g addulp               # 逐值枚举到 inf
ea-FRDT.exe 0 -m all --only fp32,dec128 -j 1,3 -q
ea-FRDT.exe 0 -m all -l 3 -t 10              # 循环 3 次，每次最多 10s
ea-FRDT.exe 0 -m f32 --json                  # JSON 输出供脚本采集
ea-FRDT.exe 0 -m f64 --dump walk.bin
```

---

*算法可能会开小差。*
