# 基准测试结果（参考测量）

测试环境：i7-6700 (4C8T), Windows x86_64, MSYS2 clang64 Clang, release `-Oz -flto=thin -static`。
命令：`float_inf_walk 0 -m <format> -q`（从 1.0 乘 1.02 到溢出）。

> 下表步数与耗时是**该构建在该机器上的历史参考测量**：步数主要由格式位宽与 Emax 决定、对构建较稳定；耗时随 CPU、优化级别与编译器显著变化，不作跨机器/跨版本承诺。对比 BID 与 DPD 时重点看“同宽度步数是否一致”，而非绝对毫秒。

## 单线程步数基准（1.0 × 1.02 → overflow）

| 格式 | 步数（参考） | 耗时（参考） |
|---|---|---|
| FP4 (E2M1) | 1 (`identity->stop`) | ~0 ms |
| FP6 (E3M2) | 1 (`identity->stop`) | ~0 ms |
| FP8 (E4M3) | 1 (`identity->stop`) | ~0 ms |
| FP8 (E5M2) | 1 (`identity->stop`) | ~0 ms |
| FP16 | 574 | 9 ms |
| BF16 | 3913 | 16 ms |
| TF32 | 4623 | 21 ms |
| FP32 | 4481 | 30 ms |
| Dec32 (BID) | 11279 | 45 ms |
| DPD32 | 11279 | 57 ms |
| FP64 | 35843 | 209 ms |
| Dec64 (BID) | 44767 | 229 ms |
| DPD64 | 44767 | 230 ms |
| x87 (80-bit) | 573521 | 3900 ms |
| FP128 | 573521 | 3911 ms |
| Dec128 (BID) | 714521 | 12244 ms |
| DPD128 | 714521 | 4868 ms |

## 说明

- FP4/FP6/FP8 从 1.0 乘 1.02 第一步即 `identity->stop`：这些极小格式里 1.0×1.02 舍入后仍等于 1.0，无进展。
- Dec32/DPD32 步数一致（11279）、Dec64/DPD64 一致（44767）、Dec128/DPD128 一致（714521）：同一十进制数学操作下 BID 与 DPD 两条编码路径的步数对齐。
- x87 与 FP128 在此构建测得相近步数（573521）；两者均为纯软件、15 位指数量级，耗时差异来自各自的宽尾数乘法实现。
- 耗时排序：宽系数的 Dec128(BID) 因 113 位系数走 UInt256 大整数乘法而最重；DPD128 走十进制数组逐 declet 运算。小宽度（dec32/dec64）上 DPD 因查表/逐位开销略慢于 BID；具体快慢随系数宽度变化，以实测为准。
- `-q` 现在只压掉实时行，退出前仍打一行 `总计 <N> 步 · <退出原因> · 墙钟 <t>`；该尾行不影响步数与耗时读数（耗时来自 `RunResult`，不含打印）。

## 默认 `-m all` 范围

默认链 13 种格式，排除：

- DPD32/DPD64/DPD128（纯软件十进制 declet，确认门提示其显著慢于原生路径）
- Dec128(BID)（UInt256 宽系数大整数乘法，确认门提示其比 DPD128 再慢约 2–3 倍）

用 `--only dpd32,dpd64,dpd128,dec128` 显式加入；该确认门仅在 `-m all` 出现。

## 常用参数实测示例（参数语义以 PARAMETERS_CN.md 为准）

- `-m fp32`：单格式；`-m all`：并发默认 13 链（默认排除 DPD×3 与 Dec128）
- `--only fp32,fp64`：格式子集
- `-g x1.02`（默认）/ `-g mululp` / `-g addulp` / `-g subulp`：步进模式
- `-k 1.01`：自定义倍率；`-a max-finite`：最大有限值起点；`-a min-normal`：最小正规格起点；`-s`：最小非规格起点
- `-a 0x3f800000`：FP32 的 1.0 Raw 位起点（hex 起点必须用 `-a`，`-s` 无参数）
- `-l 3`：循环 3 遍；`-t 10`：10 秒超时
- `-j 0,2`：指定核心（0-based，第一核为 0）；`-q`：静默；`--dump f.bin`：落盘记录（schema v2 头，头+载荷双 CRC-32 与记录几何用 `dump_inspect.py` 对账；仅单格式模式，`-m all` 只出 empty 空头部）
- `--lang zh|en`：界面语言（默认 `zh`）
