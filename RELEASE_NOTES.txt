English:
- NaN boundary check: nan->nan exit reason on native float/double paths.
- Input hardening: hex strings limited to 32 chars (128-bit), non-hex rejected.
- ANSI/control-char sanitize on all user input echoed in error messages.
- Docs updated: README/FAQ bilingual, exit reasons, safety section.

- NaN 边界检查：native float/double 路径 nan->nan 退出。
- 输入加固：hex 限 32 字符（128 位），非十六进制拒绝。
- 错误消息用户输入经 sanitize() 过滤，防 ANSI 注入。
- 文档更新：README/FAQ 双语、退出原因、安全章节。

Limitations: beta, may have undiscovered edge bugs. Algorithm may misbehave.
